## 주요 기능

| 영역 | 주요 기능 |
| --- | --- |
| ✅ **전자출결** | 빠른 출결, 과목별 주차별 출결 현황 |
| 🗓️ **과제·강의 캘린더** | 과목별 과제, 강의, 할일 캘린더, 마감 및 제출 여부, 시청 인정 여부 |
| 📤 **과제 제출** | 앱 안에서 파일 제출 및 수정 |
| 🔔 **클래스룸 알림** | 코스모스 알림 모아 보기, 파일 다운로드, 공지사항 미리보기 |
| 💺 **열람실** | 열람실 좌석 지도, 현황, 퇴실 시간 알림 |
| 🍚 **학식** | 제2기숙사 및 교직원식당 식단 확인 |
| 📝 **할 일** | 공통, 과목별, 과제별 할 일과 마감 알림, 캘린더에 표시 |

## 알아두기

- **비공식 개인 프로젝트입니다.**

    홍시는 홍익대학교가 제공하거나 보증하는 서비스가 아닙니다. 학교 시스템이 바뀌면 일부 기능이 작동하지 않을 수 있습니다.

- **중요한 기록은 학교 시스템에서 확인해 주세요.**

    출결, 과제 제출, 강의 이수, 마감 시각은 학교 시스템을 기준으로 합니다. 정보가 누락되거나 미반영 될 수 있습니다.

- **앱과 웹의 로그인 보관 방식이 다릅니다.**

    앱은 학교에 직접 로그인합니다. 자동 로그인 사용시 비밀번호, 학교 로그인 세션, 클래스룸 토큰, 홍시 로그인 토큰을 기기 보안 저장소에 보관합니다. 비밀번호는 홍시 서버에 보내거나 저장하지 않습니다.

    웹은 입력한 비밀번호를 홍시 서버로 보내 학교 로그인을 처리하며, 비밀번호를 저장하지 않습니다. 로그인 상태 유지시 학교 세션을 서버에 암호화하여 보관하고 브라우저에는 로그인 쿠키를 저장합니다.

- **동기화 및 백그라운드 확인에는 서버 데이터베이스를 사용합니다.**

    할 일 목록, 완료 표시, 좌석 이용 기록 등은 기기 간 동기화를 위해 홍시 서버에 저장됩니다. 비밀번호는 저장하지 않으며, 학교 SSO 세션을 기기별로 암호화해 최대 14일 보관합니다.

- **로그아웃은 해당 기기의 로그인과 동기화 정보를 정리합니다.**

    로그아웃 시 홍시 서버 세션, 해당 기기의 학교 인증정보 및 로그인 쿠키를 전부 삭제합니다. 

    모든 기기에서 로그아웃 시 서버에 저장된 해당 계정의 모든 로그인 세션과 저장된 인증정보를 삭제하고, 현재 기기의 인증정보도 삭제합니다. 다른 기기에서도 모두 로그아웃되며 추후 로그인 시 인증을 다시 시도해야 합니다.

- **홍시는 저장된 데이터베이스를 임의로 접근하거나 사용하지 않습니다.**

    편리하고 빠른 로그인 및 인증을 위해 저장된 정보는 모두 앱의 기능들(로그인, 출결, 알림, 과제 및 강의 조회 등)이 작동하는데만 사용되며, 암호화되어 저장됩니다.

    또한 데이터베이스에는 안전하게 암호화되어 있으며 데이터베이스에서 임의로 데이터를 내보내거나 사용하지 않습니다. 데이터베이스에 쓰거나 읽는 작업은 홍시에서만 동작합니다.

- **알림은 지연되거나 누락될 수 있습니다.**

    서버 및 기기의 네트워크 상태, 절전 및 알림 설정에 영향을 받습니다. 출석과 마감은 알림에만 의존하지 말고 직접 확인해 주세요.

- **해당 서비스 이용에 관한 책임은 사용자에게 있습니다.**

    해당 서비스 이용으로 발생할 수 있는 불이익에 대하여 책임을 지지 않습니다.
