## 주요 기능

| 영역 | 주요 기능 |
| --- | --- |
| ✅ **전자출결** | 빠른 출결, 과목별 주차별 출결 현황 |
| 🗓️ **과제·강의 캘린더** | 과목별 과제, 강의, 할일 캘린더, 마감 및 제출 여부, 시청 인정 여부 |
| 📤 **과제 제출** | 앱 안에서 파일 제출 및 수정 |
| 🔔 **클래스룸 알림** | 코스모스 알림 모아 보기, 파일 다운로드, 공지사항 미리보기 |
| 💺 **열람실** | 열람실 좌석 지도, 현황, 퇴실 시간 알림 |
| 🍚 **학식** | 제2기숙사 및 교직원식당 식단 확인 |
| 📝 **할 일** | 공통, 과목별, 과제별 할 일과 마감 알림, 캘린더에 표시 |

## 알아두기

- **비공식 개인 프로젝트입니다.**

    홍시는 홍익대학교가 제공하거나 보증하는 서비스가 아닙니다. 학교 시스템이 바뀌면 일부 기능이 작동하지 않을 수 있습니다.

- **중요한 기록은 학교 시스템에서 확인해 주세요.**

    출결, 과제 제출, 강의 이수, 마감 시각은 학교 시스템을 기준으로 합니다. 정보가 누락되거나 미반영 될 수 있습니다.

- **앱과 웹의 로그인 보관 방식이 다릅니다.**

    앱에서 자동 로그인을 활성화하면 아이디 및 비밀번호를 기기 보안 저장소에 보관합니다. (서버에 저장하지 않습니다.) 웹은 비밀번호를 저장하지 않으며, 로그인 상태 유지를 켜면 학교 세션을 서버에 암호화하여 최대 14일 보관합니다. 로그아웃하면 해당 로그인 정보를 삭제합니다.

- **동기화와 백그라운드 확인에는 서버를 사용합니다.**

    할 일 목록, 완료 표시, 좌석 이용 기록 등은 기기 간 동기화를 위해 홍시 서버에 저장됩니다. 처음 자동 로그인을 켜면 백그라운드 동기화가 기본으로 켜집니다. 5분마다 일정과 클래스룸 알림을 확인하며, 학교 세션은 암호화해 최대 14일 보관합니다. 유효한 세션으로 이용하면 보관 기한이 갱신됩니다. 설정에서 동기화를 끄면 해당 계정의 백그라운드용 세션과 기기 등록을 삭제합니다.

- **알림은 지연되거나 누락될 수 있습니다.**

    서버 및 기기의 네트워크 상태, 절전 및 알림 설정에 영향을 받습니다. 출석과 마감은 알림에만 의존하지 말고 직접 확인해 주세요.

- **해당 서비스 이용에 관한 책임은 사용자에게 있습니다.**

    해당 서비스 이용으로 발생할 수 있는 불이익에 대하여 책임을 지지 않습니다.
